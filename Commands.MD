# This file is for me in order to not forget important commands

## Virtual environment

**Start** - source vsm-venv/bin/activate

## Install and Package

**Install in editable mode (must be done in the base folder)** - pip install -e .

## Git

- **Show the current status of the repo** - git status
- **Add new changes** - git add .
- **Push to git** - git push
- **Create branch** - git checkout -b [branch-name]
- **Switch branch** - git checkout [branch-to-switch-to]
- **Push new branch upstream to github** - git push -u origin [branch-name]
